# Project instructions

Use **OrcaSlicer** as the default slicer for preparing plates, inspecting toolpaths, and reviewing printability. Use a different slicer when explicitly requested or when a required capability is unavailable in Orca; explain the fallback.

## Public website design

Use the supplied Gridline design system for GitHub Pages: square panes, System Gray and white surfaces, Active Blue titles, IBM Plex Sans and Mono, visible navigation, and semantic color blocks. Use real project renders with captions. Preserve routes, downloads, viewer behavior and scientific color scales. Shared assets and maintenance notes live in https://github.com/thereprocase/thereprocase.github.io/blob/main/GRIDLINE.md.

## Pipeline and printing notes

Read CLAUDE.md in this folder too: it records where the coupon/bracket pipeline lives (a Codex work tree on C:), the CadQuery environment, the frozen print profiles, the fit-coupon workflow, and how plates reach the P1S through the bambu-bridge on pve.
