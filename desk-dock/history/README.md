# Design history and reference material

This folder preserves the recovered project discussion, the user's intended physical arrangement and simplification markups, the earlier wider D6 geometry, and two D7 snapshots before later changes. These are historical artifacts, not current print recommendations. Use `../D7/` for the current design.

The reference photo establishes a closed Precision 5680, hinge down and lid toward the user. Dell reference assets in `reference-assets` retain their original authorship; their sources and dimensional use are documented in the D6 port study. Historical scripts and snapshots may contain machine-specific paths or superseded assumptions.

`conversation.md` is the recovered project conversation, not a current specification. Current decisions and remaining verification are collected in the root `PROJECT_CONTEXT.md`.

The original 5560 wall-mount project and its Git history remain in this repository; its original README is preserved in `docs/history/5560-README.md` and its former homepage is `docs/5560-archive.html`.
