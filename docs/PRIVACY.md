# Publication hygiene

Published research paths use generic user and workstation names. Two desktop captures containing an account identity are excluded. JPEG reference metadata was stripped without changing compressed image pixels. Public project attribution and upstream license contacts remain.

The same sanitization is applied to published branch history. Existing external clones and provider caches are outside this repository's control. Original evidence is retained privately in the local workspace.

The release native model and all 14 print meshes are unchanged by this pass. The live FreeCAD airway audit found zero patch intrusion into the original inner loft and zero missing wall. This does not establish pressure loss, thermal performance or physical print quality.
